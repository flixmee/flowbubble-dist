Guest form example

With data-guest-form="required", visitors fill in their name and phone number before they can chat. This page uses the mock backend, so the details stay in your browser. Back to the basic example.

The embed

<script
  src="flowbubble.min.js"
  data-webhook="https://your-flowapp-host/api/automation-webhooks/<automation-id>"
  data-title="Support"
  data-guest-form="required"
  data-consent-text="I agree that my details are stored so the team can contact me."
  data-open="true"
  defer></script>

How it works

The form is only the visitor-facing half. Your backend has to enforce it: it answers chat messages with 403 { "status": "error", "error": "guest_required" } until the session has registered. When the widget gets that answer, it shows the form again and resends the message afterwards.

Submit the form, then press reset(): the widget starts a new session and registers the same guest again without asking, so you see a second register event.
