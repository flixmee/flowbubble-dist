FlowBubble example

The chat bubble in the corner is the widget. This page answers it with a mock backend that runs in your browser, so nothing is sent anywhere. See also the guest form example.

The embed

This page loads the widget from JavaScript: it creates the script element and sets each option as a dataset property. On your site, point webhook at your own webhook and leave out mock-backend.js.

<script>
(function () {
  var s = document.createElement('script');
  s.src = 'flowbubble.min.js';
  s.dataset.webhook = 'https://your-flowapp-host/api/automation-webhooks/<automation-id>';
  s.dataset.title = 'Support';
  s.dataset.greeting = 'Hi! How can I help you today?';
  s.dataset.suggestions = 'Pricing|Contact|Opening hours';
  s.dataset.accent = '#6C5CE7';
  s.onload = function () {
    FlowBubble.on('reply', function (e) { console.log(e.text); });
  };
  document.body.appendChild(s);
})();
</script>

Things to try

Ask about pricing to get quick-reply chips, or send markdown to see the formatting. These words make the mock fail, so you can see the error states: error (500), bad (400), rate (429), slow (timeout after 6 s) and offline (network failure).
